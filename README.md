### Active projects

**[MedianMolding](https://medianmolding.com)** (Flutter, Python/FastAPI) — is a shop-floor system for injection molding plants. It brings
machines, molds, process parameters, maintenance, audits and OEE into one place, together with
everything that used to live in paper binders and scattered Excel files. It also detects process
parameter drift and warns before scrap is produced. It grew out of three digitalized checklists and five
years of watching what a factory actually needs. No training required: each role gets a single A4 page
that explains everything. Currently being deployed to production.

**[Lantern Walk - live wallpaper](https://play.google.com/store/apps/details?id=sk.lubos.lanternwalk)** (Kotlin, libGDX) — Lantern Walk isn’t an animation that plays on a loop. It is a small world that runs alongside your day: the mist rises in the morning, the campfire is lit in the evening, and fireflies take flight at night; when it rains where you are, it rains here too. Things within it slowly grow, accumulate, and remain—plants sprout and grow throughout the week, the woodpile dwindles and is replenished, and the items you find are stored in your Collection. Nothing here is in a rush.

**[psychodiary](https://play.google.com/store/apps/details?id=sk.xamples369.psychodiary&hl=en)** (Flutter) — a mobile-first journal for personal
mental-health tracking. Four quiet screens, a small JSON archive on the device, no cloud,
no notifications, no streaks. Designed for reflection, not engagement.

**[Return to Novus](https://returntonovus.com)** (Flutter, Python/FastAPI, Lua) — a full control panel for an RF Online private server. 
Unified Flutter codebase powering a cross-platform GameCP (Web/Mobile) and a native Windows launcher featuring auto-updates for both the game client and the launcher itself. Integrated bi-directional communication with the zone server core via Lua-scripted hooks, enabling real-time game state synchronization and remote management directly from the control panel. Two clients · one backend · one auth model — FastAPI split between a VPS and a bridge running on the game server itself, talking to SQL Server through tunnels. Years ago, an RF Online server was where I first discovered the joy of digging through code. I walked away because it led nowhere. This is the walk back — built properly this time.

**[Lantern Walk](https://github.com/xamples369/lantern-walk)** (Godot) — an interactive world in Godot where physics
can be experienced instead of read. A calm forest clearing with a day/night cycle as the main menu; real-time star sky, 
paths lead to hands-on visualizations of magnetism, electricity, waves. The measure of done:
*would someone who never liked or understood physics stop and stay?*
